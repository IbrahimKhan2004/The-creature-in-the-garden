# The Creature in the Garden

A dark psychological short story presented as an immersive, novel-style web experience.

🔗 **Live:** [ibrahimkhan2004.github.io/The-creature-in-the-garden](https://ibrahimkhan2004.github.io/The-creature-in-the-garden)

---

## About

A man spends his birthday running from a monstrous creature that no one else can see — only to discover, too late, what it truly was.

A story about fear, assumption, and the people we destroy before we understand them.

---

## Built With

- Pure HTML + CSS + Vanilla JS
- No frameworks, no dependencies
- Google Fonts — Cormorant Garamond & Crimson Pro
- Scroll-reveal animations via IntersectionObserver
